# Job Application Automation

An automated job application workflow built with n8n that collects applicant information through an online form, stores the submitted data in Google Sheets, and sends an email notification automatically.

## Overview

This project demonstrates how workflow automation can simplify the job application process.

Applicants submit their information through a web-based job application form. The workflow receives the submission, stores the applicant details in Google Sheets, and then sends an email notification to the designated recipient.

## Features

- Online job application form
- Applicant information collection
- Google Sheets data storage
- Automatic email notification
- n8n workflow automation
- No manual data entry required

## Applicant Information

The application form collects:

- Name
- Email
- City
- Phone Number
- Tech Stack

## Workflow

The automation follows this process:

Job Application Form
        ↓
n8n Workflow
        ↓
Google Sheets
        ↓
Email Notification

## Technologies Used

- n8n
- Google Forms / n8n Form Trigger
- Google Sheets
- Gmail
- Workflow Automation

## How It Works

1. An applicant opens the job application form.
2. The applicant enters their personal and technical information.
3. The form submission triggers the n8n workflow.
4. Applicant information is stored in Google Sheets.
5. An email notification is automatically sent to the designated recipient.

## Project Purpose

The purpose of this project is to demonstrate how n8n can be used to automate repetitive recruitment tasks and connect multiple services into a single workflow.

Instead of manually collecting applications, entering applicant information into a spreadsheet, and notifying the recruiter, the entire process can be handled automatically.
